# JavaScript ES6 Object Array Destructuring

This example demonstrates various features of ES6 Object and Array Destructuring in JavaScript. It covers basic extraction, renaming properties/elements, setting default values, using rest syntax, and destructuring nested structures. The output is logged to the browser's developer console.

## Language

`html`

## How to Run

1. Save the code as `index.html`.
2. Open `index.html` in any modern web browser.
3. Open the browser's developer console (F12 or Ctrl+Shift+I) to view the logged output.
