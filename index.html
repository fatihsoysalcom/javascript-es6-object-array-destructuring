JavaScript ES6 Object and Array Destructuring

This page demonstrates various forms of ES6 Object and Array Destructuring in JavaScript. Open your browser's developer console to see the output of each example.

How to view output:
  1. Open this index.html file in any modern web browser.
  2. Press F12 (Windows/Linux) or Cmd+Option+I (macOS) to open the developer tools.
  3. Navigate to the "Console" tab to see the logged examples.
